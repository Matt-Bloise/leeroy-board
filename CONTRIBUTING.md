# Contributing

This repo is the published copy of a private source tree; the source holds the party's personal records, so it stays private. Open one small PR per issue against master here; accepted commits are ported into the source with your authorship kept and come back with the next publish (rebase if a publish overwrites your branch).

We accept a before and after number on a stated device (frame time, long animation frames, bytes, render counts).

We do not accept CI that deploys anywhere, secrets in the repo, changes to authentication, or first names or Discord ids in code or copy.
