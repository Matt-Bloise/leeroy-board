Get the add-on

Leeroy Build is a small add-on for WoW Forever. It writes your own character (class, race, level, professions) as one line of text that you copy in the game. You paste that line on this site, check what it found, and choose whether to send it.

This is an early version. Tell us if it will not load.

Install on Windows

  1. Close the game.
  2. Save the zip, then right-click it and choose Extract All.
  3. Open the AddOns folder of your WoW Forever install, the one that already holds your other add-ons.
  4. Move the extracted LeeroyBuild folder in. The result must be AddOns\LeeroyBuild\LeeroyBuild.toc.
  5. Start the game. At the character screen, open AddOns and make sure Leeroy Build is ticked. If it says out of date, tick Load out of date AddOns.

Install on Mac

  1. Quit the game.
  2. Double-click the zip in Finder to unpack it.
  3. Open the AddOns folder of your WoW Forever install, the one that already holds your other add-ons.
  4. Move the LeeroyBuild folder in. The result must be AddOns/LeeroyBuild/LeeroyBuild.toc.
  5. Start the game. At the character screen, open AddOns and make sure Leeroy Build is ticked. If it says out of date, tick Load out of date AddOns.

How to import

  1. In the game, type /leeroy export. A window opens with the line already selected.
  2. Press Ctrl+C (Cmd+C on a Mac) to copy it, then Esc.
  3. On this site, open your own sheet and choose Import from game.
  4. Paste the line.
  5. Check the summary it shows.
  6. Tap Send N changes to my sheet (N is the number of lines that differ from your sheet).

What it exports

  • Always: a format tag, the game's interface number, and the time of the export.
  • On by default: class, race, level and your primary professions.
  • Off by default: character name, talent points per tree, and current zone. Turn them on with /leeroy options.
  • Not exported: other players, chat, guild, friends, your account name, or file paths.

The add-on sends nothing anywhere. It has no network code. Nothing leaves the game unless you copy the line and paste it yourself. To remove it, delete the LeeroyBuild folder.

If something goes wrong

This is an early add-on. If it does not load or shows an error, type /console scriptErrors 1, then /reload, and repeat what you did. Copy the error text and send it to Matt with your interface number (/dump select(4, GetBuildInfo())). Turn the popup off again with /console scriptErrors 0.
